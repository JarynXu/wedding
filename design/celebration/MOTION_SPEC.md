# 宾客祝福与礼物

## 视觉与信息

四页共用一处左下角入口，进入请柬后开放。音乐、翻页、日历和地图保留现有位置。发送面板复用奶油毛玻璃与金边。法式使用酒红圆角按钮、玫瑰与香槟；中式使用朱红折角面板、双喜、灯笼和同心结。礼物为透明实物质感图集，来源见 `gifts-provenance.json`、`image-prompt.txt`。

“送祝福”负责称呼、留言和礼物选择；“祝福簿”负责历史查阅。页面只展示数据库确认的内容。初次进入出现的历史气泡注明“留在祝福簿的心意”，不触发礼物效果。

## 动作

| 对象 | 行为 | 时间与范围 |
|---|---|---|
| 祝福气泡 | 左下侧出现，向上浮动后渐隐 | 7.2 秒；174 像素；两条上限；相隔至少 3.2 秒 |
| 玫瑰 | 玫瑰抬升，白粉红花瓣绕过 | 3.4 秒；人物侧边 |
| 香槟 | 双杯轻摆，金色细泡上升 | 3.4 秒；左侧 |
| 烟花 | 细光线升起，左右两束先后展开 | 3.4 秒；上方两侧，酒红/暖金 |
| 喜灯 | 暖光透出，灯笼上升 | 3.4 秒；左侧 |
| 同心结 | 挂结摆动与金色光点 | 3.4 秒；左侧 |
| 双喜 | 印章落定，细金圈消散 | 3.4 秒；左侧 |

画布不接收指针事件，DPR 上限为 2，无新增音效。一次播放一份礼物；消息洪峰的视觉队列有上限，全部原文仍在祝福簿中。切到后台清空动画并关闭实时连接，返回后按游标补读。关闭“飘屏祝福”保留发送与历史。减少动态效果时使用静态短提示，停止礼物画布。

## 验收

双端发送与收取；两主题互通；历史礼物不重播；消息按文本显示；保存后响应中断重试不重复；320/375/390/414/768 像素布局；弹窗输入字号 16 像素；下一页点击区不与祝福入口相交；键盘焦点返回；减少动态效果；现有人像与加载流程回归。
