# 中式主题

URL 使用 `theme=chinese`；无参数、未知值或重复值沿用法式版。家长邀请参数、分享地址与日历往返保留主题选择。

用户提供的五张设计稿承担美术参考，内容使用当前请柬配置：开场不出现新人姓名、时间或地点；第一页显示人物与姓名；第二页显示时间与日历操作；第三页显示地点与地图操作；末页按新人或父母身份发出邀请，不恢复 INVITATION 英文行。

画面使用清理后的摄影装饰底图、HTML 文字与按钮、SVG 酒店图标和花瓣 Canvas。各页使用朱红、象牙白与金色。当前 Vite 与原生 CSS 动效承担运行，不引入新框架。

入场由点击开启请柬触发，等待当前主题的图片、字体与完整音乐就绪。开场预览与必要样式进入原始 HTML；外部 CSS/JS 失败保留首帧与重试入口。未选主题的背景不进入预加载清单。

页面切换沿用 840ms 连续叠化；文字在 140ms 后按阅读顺序展开。中式人物图层使用 1400ms 的不透明度与 1.025→1 等比缩放，印章使用 800ms 的落印效果。花瓣沿用按时间计算的轨迹。减少动态效果时显示最终静态画面，停止装饰动画。

迎宾照的礼服、盘发与环境由图像工具生成。脸部取自用户原始合照，眼距决定等比缩放、眼睛中点决定平移；仅轮廓边缘羽化，脸部不调色、不重绘、不拉伸。源文件、掩膜轮廓与合成记录位于本目录，最终肖像为无损 WebP。

验收覆盖 320×568、390×844、430×932 与桌面预览；检查当前主题首帧、人物五官、页内内容、前后翻页、动态与静态画面、弹窗、日历返回参数、分享参数及旧主题回归。面部原始像素与最终合成的对应区域须核对。
