# Scene specifications

All frames use the same `390 × 844` mobile portrait baseline and the shared token set in `../04-spec/design-tokens.json`. Text remains live UI except where explicitly marked as visual art. Final raster assets follow `../04-spec/asset-production.md`.

## 01 — Cover

**Primary anchor:** original couple welcome portrait.

**Composition:** portrait centered, deep-brown velvet curtains on left/right, red-white-pink floral clusters at top/bottom, live gold/ivory name + date near lower third.

**Depth order:** base atmosphere → rear curtain → photo → rear florals → live copy → front florals → subtle grain/light.

**Motion:** very low-amplitude photo settle; curtains breathe outward as scrolling begins; foreground florals move slightly faster than photo.

**Do not:** regenerate faces, darken the whole frame into near-black burgundy, bake names/date into the photo.

## 02 — Announcement

**Primary anchor:** “我们要结婚了”.

Warm ivory/champagne field with a soft foil ring/halo and a few drifting rose petals. This scene must feel like the cover has opened into light, not like a new template.

## 03 — Time

**Primary anchor:** year/date, followed by the three schedule times.

The gold ring continues from scene 02 as a continuity device. Florals enter from opposite edges at reduced density. Information must remain readable on 320 × 667 without clipping.

## 04 — Message

**Primary anchor:** short invitation/relationship sentence.

Use translucent fabric/veil and sparse petals as atmosphere. This is the quietest emotional beat before location information. Avoid large floral clusters behind copy.

## 05 — Location

**Primary anchor:** venue name and address.

Architecture/venue art occupies the middle/back plane; florals stay primarily low. Navigation is a real HTML control and becomes enabled only when a valid map URL is configured.

## 06 — Transition

**Primary anchor:** spatial reveal.

Deep-brown curtains open farther than on the cover and reveal warm aisle/light. Red, white and pink florals run along both sides. This is the most spatial motion moment, but copy remains short.

## 07 — Couple

**Primary anchor:** second crop of the original couple photo.

Use the same grade, lighting family and floral language as scene 01. The photo can be closer/more intimate, but must remain the same real people and original image source unless another approved photograph is supplied.

## 08 — Full invitation

**Primary anchor:** complete invitation wording.

A vertical paper invitation with restrained foil border, red/white/pink florals only at controlled corners, and nearly static motion. All names, date, time, venue, address and invitation wording remain live text.

The invitation page must remain legible first and decorative second. No floral cluster may invade the core text column.
