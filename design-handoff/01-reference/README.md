# Reference authority

**Approved direction:** Version 6 from the design conversation.

The implementation preserves the decisions established by that direction:

- warm cream/champagne field rather than blackened red;
- deep-brown velvet curtain treatment;
- red + white + pink floral language;
- warm restrained gold / foil character;
- real couple welcome portrait as the principal identity image;
- mobile portrait composition;
- final full invitation as a vertical paper/foil card;
- continuous scroll-driven visual storytelling rather than page snapping.

The browser-rendered implementation baseline lives in `../02-scene-concepts/` and is the inspectable handoff reference for engineering.
