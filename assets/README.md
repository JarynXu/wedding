# Runtime assets

Key visual layers are raster assets derived from the supplied couple and wedding-stage references. Critical photographic layers must not be replaced with flat SVG illustrations.

```text
assets/
├── audio/
│   └── wedding.mp3               # optional; not yet supplied
├── common/
│   ├── curtain-left.webp         # deep-brown real velvet fold layer
│   ├── curtain-right.webp
│   ├── floral-side.webp          # real red / white / pink flower cutout
│   ├── floral-bottom.webp        # retained source cutout
│   ├── floral-garland.webp       # composed horizontal real-floral layer
│   ├── paper.webp
│   └── gold-foil.webp
├── photos/
│   └── welcome.webp              # supplied real couple portrait
├── scene-05/
│   └── venue.webp                # real venue/stage atmosphere
└── scene-06/
    └── reveal.webp               # real stage reveal, curtain regraded brown
```

SVG is appropriate only for simple icons or geometric marks. Names, dates, venue details, invitation copy, navigation labels, music controls and page numbers remain live HTML text/UI.
