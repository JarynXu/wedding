# Wedding Invitation · 第六版

移动端竖版婚礼电子请柬。视觉以第六版效果图为准：奶油白与香槟金为底，深棕色丝绒帷幔，红、白、粉花艺，新人双人迎宾照，以及烫金流金请柬终页。

## 在线地址

GitHub Pages：`https://jarynxu.github.io/wedding/`

## 替换两张迎宾照

将照片放到 `assets` 目录并保持以下文件名：

- `assets/welcome-1.jpg`：封面迎宾照
- `assets/welcome-2.jpg`：倒数第二页新人照

建议使用竖图，比例约为 `3:4` 或 `4:5`，长边不低于 1800px。提交到 `main` 后，GitHub Actions 会自动重新发布。

没有自定义照片时，构建流程会使用仓库中的兼容回退图，保证页面不会出现空白。

## 配置背景音乐

将 MP3 文件放到：

`assets/music.mp3`

移动浏览器限制自动播放，宾客需要点击右上角音乐按钮后开始播放。

## 修改请柬内容

请柬姓名、日期、时间、地点、流程及邀请文字均在 `index.html` 中；地图链接位于地点页面的 `a.map-button`。

## 页面结构

1. 帷幔花艺迎宾封面
2. 婚礼宣告
3. 婚礼时间与流程
4. 邀请寄语
5. 婚礼地点与导航
6. 仪式空间过渡
7. 新人迎宾照
8. 移动端竖版烫金请柬全文

页面使用固定舞台式滚动：浏览器保持一屏画面，纵向滚动连续驱动画面淡入、位移、景深及视差变化；同时支持触摸滚动、键盘翻页、章节导航和减少动态效果设置。
