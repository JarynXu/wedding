# Wedding Invitation

移动端竖版婚礼电子请柬，按照“第六版效果图”的视觉方向实现：奶油白与香槟金为主色，深棕色帷幔，红、白、粉花艺，双人迎宾照，烫金流光，以及固定视口的分镜式上下滑动。

## 已实现

- 8 个全屏分镜：封面、结婚宣告、时间、寄语、地点、相见、新人照、请柬全文
- 鼠标滚轮、触摸上滑/下滑、方向键和分页按钮切换
- 固定页面滚动，滚动动作驱动画面转场
- 深棕帷幔、红白粉花艺、纸张纹理、流金文字、花瓣和光影动效
- 两张迎宾照可独立替换
- 背景音乐播放、暂停和文件替换
- 高德地图导航链接
- 移动端安全区、竖屏提示、键盘操作和“减少动态效果”适配
- GitHub Pages 自动部署工作流

## 修改姓名、日期、地点与文案

编辑根目录的 [`config.js`](./config.js)。所有可变内容集中在该文件，包括：

- 新人姓名、连接符和姓名首字母
- 婚礼日期、星期、仪式时间与日程
- 酒店名称、英文名、地址和地图链接
- 宣告、寄语和请柬全文
- 照片、现场图与音乐路径

仓库中的姓名、日期和地点是第六版效果图使用的示例内容，不代表最终婚礼信息。

## 替换两张迎宾照

默认文件：

```text
assets/photos/cover.webp     # 第 1 页封面迎宾照
assets/photos/portrait.webp  # 第 7 页新人迎宾照
```

直接用同名文件覆盖即可，无需改代码。也可以上传 JPG/PNG，然后在 `config.js` 中修改 `media.coverPhoto` 和 `media.portraitPhoto`。

建议：

- 竖版构图，接近 9:16
- 长边不少于 1600px
- 主体居中，四周预留花艺和文字空间
- 优先使用 WebP，单张建议控制在 500KB 以内

婚礼现场图位于 `assets/photos/venue.webp`，用于“期待与您相见”页面，也可用同样方式替换。

## 替换音乐

默认音乐：

```text
assets/music/wedding-ambient.mp3
```

可直接覆盖同名文件，或在 `config.js` 中修改 `media.musicSrc`。浏览器不会自动播放有声媒体，宾客需要点击右上角音乐按钮。请只使用你拥有授权的音乐。

## 本地预览

这是无构建依赖的静态网站。在仓库目录运行：

```bash
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。

## GitHub Pages

推送到 `main` 后，`.github/workflows/pages.yml` 会构建并部署根目录静态文件。首次使用时，仓库的 **Settings → Pages → Source** 需要设置为 **GitHub Actions**；后续提交会自动发布。
